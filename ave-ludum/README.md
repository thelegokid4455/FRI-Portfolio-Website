# Ave Ludum Studio Website

Static HTML/CSS/JS site designed to use the same simple editing model as the FRI portfolio.

## Edit content
Update `content.js`. No build step is required.

## Vercel
Create a separate Vercel project using the same GitHub repository and set **Root Directory** to `ave-ludum`.

The existing portfolio remains untouched at `portfolio-site`.
